# Hotel Service

Приложение `ru.mephi.hotel.HotelApplication`, порт 8082, собственная H2 `hotel-service`. Управляет отелями, номерами, проекцией занятости и статистикой. Полный контракт: [API](../docs/api.md).

Пакеты: domain - JPA, repository - запросы и блокировки, service - каталог и операции слотов, api - DTO и контроллеры, config - безопасность и предзаполнение. Контроллеры не работают с репозиториями напрямую.

Подтверждение и освобождение блокируют одну строку Room. Полуоткрытые даты проверяются запросом пересечения. Отдельная SecurityFilterChain проверяет внутренний JWT, остальные маршруты - пользовательский. Все административные методы имеют @PreAuthorize.

Сборка из корня: `mvn -pl hotel-service -am verify`. Запуск готового JAR: `java -jar hotel-service/target/hotel-service-1.0.0.jar`. Зависимости версионируются родительским BOM и загружаются Maven автоматически. Eureka задаётся EUREKA_URL, предзаполнение - SEED_DATA. H2 Console выключена.

`InventoryIntegrationTest` проверяет реальные H2-транзакции, 12 одновременных запросов на один слот, 24 повторные доставки, отмену до позднего подтверждения, рекомендации, статистику и права через MockMvc. Для тестов Eureka отключена.
