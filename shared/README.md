# Общая библиотека

Модуль не является микросервисом и отдельно не запускается. Содержит транспортные DTO, DateWindow, RoomRanking, ApiError, загрузку открытых ключей и общую конфигурацию Servlet Security. Gateway не сканирует servlet-классы и использует собственную реактивную цепочку.

Контракты не содержат JPA-сущностей. Межсервисные связи передаются идентификаторами; закрытых RSA-ключей здесь нет. Открытые демонстрационные ключи используются при проверке подписи. Для Hotel и Booking общие RestErrors подключаются явным @Import.

Сборка: `mvn -pl shared verify`. DateWindowTest проверяет границы дат, сортировку и безопасную нормализацию traceId. Независимые от Spring классы дополнительно проверяются scripts/local-checks.ps1 через реальный javac без Maven.
